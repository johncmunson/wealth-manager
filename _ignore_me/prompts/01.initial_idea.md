I would like to build an online agentic brokerage that is built on top of Alpaca and places emphasis on long-term investing. Users should be able sign-up, fund their account, create a portfolio strategy, place orders and trades, rebalance their portfolio, conduct basic market research, etc.

The core user experience should center on a chat-based wealth manager AI agent, but "chat-based" should not imply a plaintext-only interface or the absence of rich UI. The product should feel less like early ChatGPT v1 and more like modern ChatGPT: the conversation is the primary surface, but the agent can render generative UI widgets, controls, charts, tables, portfolio allocation views, order previews, approval dialogs, and other interactive components inline whenever they make the task clearer or safer. Supplemental traditional pages may still exist for things like onboarding, funding, account settings, documents, and compliance flows, but they should support the conversational workflow rather than replace it.

The wealth manager agent will have skills and tools at its disposal enabling it to carry out all core investing and trading tasks, such as market research, executing trades, balancing a portfolio in accordance with the portfolio strategy, etc.

Furthermore, the user should be able to coordinate with the wealth manager agent in order to schedule recurring, out-of-band operations, such as automated portfolio rebalancing according to a set of predefined rules. For example, "once a quarter" or "when the portfolio drifts over 10% away from the target". Automated tax-loss harvesting and dollar-cost averaging are also good candidates for scheduled background operations.

Primary goal: An online agentic brokerage that emphasizes long-term investing and doesn't overwhelm the user with a million different features and strategies. It focuses on the basics and does them really fucking well.

Non-goals: An online brokerage that does anything and everything. Utilizing or taking advantage of the entirety of capabilities exposed by Alpaca.

Additional Notes:

- It may be more intuitive to think of this less as a traditional app and more like an agent harness that is optimized for long-term investing, is wrapped in a multi-tenant architecture, and is exposed through via a web-based modern agentic chat interface.
- For MVP, we should rely strongly on agentic intelligence to do the right thing, rather than inventing a bunch of different safety mechanisms and deterministic harness guardrails. With that said, there may be some things that we want to deterministically enforce. For example, if Tenant A is logged in and is working with the wealth manager agent, then the agent session should be scoped to Tenant A. It should not be possible for the agent to access Tenant B in this context.
